# Raw Data

This directory contains the original, immutable source dataset used by the project.

## Dataset

**Name:** Telecom Churn Dataset
**Source:** Mendeley Data
**Publisher:** Mendeley Data
**Dataset record:** https://data.mendeley.com/datasets/nrb55gr66h/1

## Usage

The original dataset must not be manually modified.

All cleaning, validation, feature engineering, and transformations must be performed programmatically and stored outside this directory.

## Project copy

The project uses the downloaded CSV:

`telecom_churn.csv`

## Provenance

The dataset represents business-customer records from a telecommunications operator and contains customer/service, subscriber, revenue, and churn information.

## Reproducibility

The raw dataset should be treated as an immutable input to the ML pipeline.

If the raw file is replaced with a newer dataset version, the dataset version/hash must be updated in the project documentation.
